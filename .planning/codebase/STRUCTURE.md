## Directory Purposes

**`assets/`:**
- Purpose: Stores app branding, splash screens, and icon assets used across platforms
- Contains: PNG image files formatted for standard, adaptive Android, and web favicon sizes
- Key files: `assets/icon.png`, `assets/splash-icon.png`, `assets/android-icon-foreground.png`

**`.expo/`:**
- Purpose: Temporary state generated by Expo CLI during execution
- Contains: Types generated by Expo (`.expo/types/**/*.ts`) and Metro bundler cache
- Key files: Automatically generated; not committed to git

**`.agents/`:**
- Purpose: Workflow automation scripts, GSD skills, core binaries, and templates
- Contains: Node.js scripts (`gsd-tools.cjs`), markdown skills, agent specifications
- Key files: `.agents/skills/`, `.agents/gsd-core/bin/gsd-tools.cjs`

## Key File Locations

**Entry Points:**
- `index.ts`: Application root entry invoking `registerRootComponent(App)`
- `App.tsx`: Main dashboard screen rendering feature cards and navigation

**Configuration:**
- `app.json`: Expo application manifest (name, slug, orientation, splash, adaptive icons)
- `package.json`: NPM package configuration, dependencies, and command scripts
- `tsconfig.json`: TypeScript configuration extending `expo/tsconfig.base`
- `eslint.config.js`: ESLint flat config setup with `eslint-config-expo/flat`
- `AGENTS.md`: Core system guidelines, routing instructions, and commands

## Naming Conventions

**Files:**
- React Components: PascalCase (e.g. `App.tsx`)
- Code Entry / Utilities: camelCase (e.g. `index.ts`)
- Configuration Files: kebab-case or dot-prefixed (e.g. `app.json`, `eslint.config.js`, `tsconfig.json`)
- Agent Instructions / Rules: UPPERCASE.md (e.g. `AGENTS.md`, `LICENSE`)

**Directories:**
- Feature / Source Folders: lowercase or kebab-case (e.g. `assets/`, target `src/components/`, `src/app/`)

## Where to Add New Code

**New Feature Screens:**
- Primary code: Per `AGENTS.md`, route files should be added under `src/app/` (e.g. `src/app/wifi.tsx`, `src/app/bluetooth.tsx`, `src/app/map.tsx`).
- Navigators: Define in `src/app/_layout.tsx`.

**New UI Components:**
- Implementation: Reusable presentation components should be extracted from `App.tsx` into `src/components/` (e.g. `src/components/FeatureCard.tsx`, `src/components/BottomNavBar.tsx`).

**Hardware & Scanning Services:**
- Wi-Fi Scanner: `src/services/wifi.ts` or `src/hooks/useWifiScanner.ts`
- Bluetooth Scanner: `src/services/bluetooth.ts` or `src/hooks/useBluetoothScanner.ts`

**Design Tokens & Theme:**
- Shared constants: Extract `COLORS` from `App.tsx:25-35` into `src/constants/colors.ts` or `src/theme/index.ts`.

**Tests:**
- Unit & Component tests: Co-locate alongside components (e.g. `src/components/__tests__/FeatureCard.test.tsx`) or in `__tests__/`.

## Special Directories

**`assets/`:**
- Purpose: Static image assets
- Generated: No
- Committed: Yes

**`node_modules/`:**
- Purpose: Third-party dependencies
- Generated: Yes (via `npm install`)
- Committed: No (ignored via `.gitignore`)

**`.expo/`:**
- Purpose: Expo temporary files and generated types
- Generated: Yes (via `expo start`)
- Committed: No (ignored via `.gitignore`)
